# PartiGen

Project page for **PartiGen: Part-Aware Representations for Language-Conditioned Humanoid Motion Generation**.

- Paper: https://arxiv.org/abs/2610.13373
- Project page: https://andyhuangzz01.github.io/partigen-paper/
- Chuxuan Huang and Zhanxiang Cao contributed equally.

The page includes the complete real-world Unitree G1 demonstration, a 22-second cover edit, and six original-speed motion clips. Page design is inspired by [BeyondMimic](https://beyondmimic.github.io/).

## GitHub Pages

This repository is a buildless static site. Publish from the `main` branch and `/ (root)` directory in **Settings → Pages**. The `.nojekyll` file keeps the static assets intact.
